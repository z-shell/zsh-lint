## Minimized parser-gap evidence

Both fixtures are accepted by the installed native Zsh syntax checker and
rejected by the public `zsh-lint-survey` path. They deliberately remain
`gap-*` fixtures until the corresponding parser support is implemented.

### Try/always, issue #12

Fixture: `internal/survey/testdata/corpus/gap-12-try-always.zsh`

```zsh
# -*- mode: zsh; sh-indentation: 2; indent-tabs-mode: nil; sh-basic-offset: 2; -*-
# vim: ft=zsh sw=2 ts=2 et
# Issue #12: Zsh try/always blocks are valid complex commands but are not
# parsed by the current mvdan/sh LangZsh front end.
{
  :
} always {
  :
}
```

With the current directory set to `$ZSH_LINT_ROOT`:

- `zsh -f -n internal/survey/testdata/corpus/gap-12-try-always.zsh`: exit 0.
- `go run ./cmd/zsh-lint-survey internal/survey/testdata/corpus/gap-12-try-always.zsh`:
  exit 1 at `7:3`, `statements must be separated by &, ; or a newline`.

The released [Zsh Shell Grammar, Complex Commands](https://zsh.sourceforge.io/Doc/Release/Shell-Grammar.html#Complex-Commands)
documents `{ try-list } always { always-list }`. The released manual and
native Zsh are authoritative for this syntax; the mvdan/sh front end is a
supplemental parser.

When checked on 2026-08-14, [try/always issue #12](https://github.com/z-shell/zsh-lint/issues/12)
was open and narrowed to this construct. The upstream
[mvdan/sh issue #1211](https://github.com/mvdan/sh/issues/1211),
`zsh: support { try-list } always { always-list }`, was also open when
checked on 2026-08-14.

### Alternate brace-form `if`, issue #125

Fixture: `internal/survey/testdata/corpus/gap-125-alternate-if-brace.zsh`

```zsh
# -*- mode: zsh; sh-indentation: 2; indent-tabs-mode: nil; sh-basic-offset: 2; -*-
# vim: ft=zsh sw=2 ts=2 et
# Parser gap: alternate brace-form Zsh if commands do not parse under the
# current mvdan/sh LangZsh front end. The numeric filename component names the
# owning z-shell/zsh-lint issue.
if [[ 1 ]] {
  :
}
```

With the current directory set to `$ZSH_LINT_ROOT`:

- `zsh -f -n internal/survey/testdata/corpus/gap-125-alternate-if-brace.zsh`:
  exit 0.
- `go run ./cmd/zsh-lint-survey internal/survey/testdata/corpus/gap-125-alternate-if-brace.zsh`:
  exit 1 at `6:12`, `statements must be separated by &, ; or a newline`.

The released [Zsh Shell Grammar, Alternate Forms for Complex Commands](https://zsh.sourceforge.io/Doc/Release/Shell-Grammar.html#Alternate-Forms-For-Complex-Commands)
documents `if list { list }` when the condition is suitably delimited. The
released manual and native Zsh are authoritative for this syntax; the
mvdan/sh front end is a supplemental parser.

When checked on 2026-08-14, the
[alternate brace-form `if` issue #125](https://github.com/z-shell/zsh-lint/issues/125)
was open and owned this separate feature-level gap.
